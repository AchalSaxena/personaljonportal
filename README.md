# Job Vacancy Intelligence Dashboard

A modern, responsive **Job Vacancy Dashboard** designed in a **Navy Blue, White, and Teal** color scheme featuring an **Excel spreadsheet-style table** with live AutoFilter, sorting, search, and direct application links.

---

## Key Features

- **Navy Blue, White, and Teal Design System**:
  - Light grey background (`#F4F6F9`), white cards, dark navy headings.
  - Blue action buttons (`Apply →`) and green badges for high-match opportunities ($\ge 85\%$).
  - Clean, minimal, and professional corporate aesthetic.

- **Excel Spreadsheet-Style Table**:
  - Clearly defined cell borders & gridlines (`1px solid #CBD5E1`).
  - Zebra striping (alternating row backgrounds) and active row selection highlight.
  - Compact row height toggle (*Normal* vs *Compact*).
  - Sticky table headers pinned on vertical scroll.
  - Dedicated row index numbers (`# 1` through `# 23`).

- **Excel AutoFilter Dropdowns on Every Column**:
  - Filter trigger buttons (`▼`) on all column headings (*Job Title*, *Organization*, *Category*, *Match Score*, *Qualification*, *Experience*, *Location*, *Salary*, *Last Date*, *Eligibility*).
  - In-column search box to find values quickly.
  - Multi-select value checklist with item counts and `(Select All)`.
  - Multi-column filtering (AND logic across multiple headings).
  - Active filter indicators on column headers and a top filter chips bar.

- **Data Export & Quick Inspection**:
  - Client-side **Export CSV** for direct editing in Microsoft Excel.
  - Row inspector modal for complete job specifications and official advertisement breakdowns.

- **Verified Opportunity Feed**:
  - Curated opportunities spanning **Consultant**, **Young Professional (YP)**, **Information Technology (IT)**, **Cyber Security / CISO**, and **eGovernance / Technical Project Management** across Government of India departments, PSUs, and banking institutions.

---

## Getting Started

1. Clone or download this repository.
2. Open `index.html` or `job_vacancies.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari).
3. No build step or local server required.
